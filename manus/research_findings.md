## 核心发现

### 1. 能带融合点 (Band-Merging Point)
- Logistic 映射在参数 u ≈ 1.5437 处存在能带融合点
- 在此临界参数下，混沌吸引子展现出"宇称刚性"(Parity Rigidity)
- 这一点在拓扑上禁止某些轨道模式，与素数的算术约束形成同构

### 2. 拓扑同构
- 素数筛法的算术约束与 Logistic 映射在能带融合点的符号动力学之间存在拓扑同构
- 素数统计可以从低维确定性物理系统中自然涌现

### 3. 孪生素数常数
- 模型定量再现了孪生素数常数 C₂ ≈ 0.6602
- 衰减指数严格受数论公理约束

### 4. 理论意义
- 算术随机性不是噪声，而是弱混沌的特征
- 提供了连接离散数论世界与连续非线性动力学世界的统一物理框架

## 揉捏理论 (Kneading Theory) 核心概念

### Milnor-Thurston 揉捏理论
- 用于研究区间分段单调自映射的拓扑动力学
- 揉捏矩阵 N(t) 的元素是整系数形式幂级数环 Z[[t]] 中的元素
- 包含映射的重要组合和拓扑不变量信息

### 单峰映射 (Unimodal Maps)
- 定义: f:[0,1]→[0,1]，存在临界点 c∈(0,1)
- f 在 [0,c] 上严格递增，在 [c,1] 上严格递减
- Logistic 族: f_μ(x) = μx(1-x)，其中 0 < μ ≤ 4

### 符号动力学
- 对于 x ∈ [0,1]\Γ，定义揉捏坐标 θ(x)
- θ_0(x) = +1 如果 x < c，θ_0(x) = -1 如果 x > c
- 揉捏行列式 D(t) 表达了揉捏坐标在临界点 c 处的不连续性

### 拓扑熵
- h(f) = log s，其中 s 是增长数
- 拓扑熵为正当且仅当 D(t) 在 (0,1) 内有零点
